# 🚀 Healthray Management System

A Semi-Agentic AI-powered Healthcare Management System built using React, Next.js, Node.js, Prisma ORM, Tailwind CSS, and OpenRouter API.

## Features

- AI chatbot integration
- Appointment management
- Role-based authentication
- Doctor & patient dashboard
- REST APIs
- Prisma ORM integration

## Tech Stack

Frontend:
- React
- Next.js
- Tailwind CSS

Backend:
- Node.js
- Express.js
- Prisma ORM

AI:
- OpenRouter API

## Project Structure

/client  -> Frontend
/server  -> Backend
